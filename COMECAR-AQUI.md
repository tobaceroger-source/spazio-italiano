# Como o novo gestor assume

## 1. Receber acesso ao repositório

Repositório: https://github.com/tobaceroger-source/spazio-italiano

O proprietário deve adicionar a conta GitHub do novo gestor como colaboradora. O gestor aceita o convite e autoriza esse repositório na conexão GitHub do próprio ChatGPT. O acesso privado ao repositório e a autorização do aplicativo são etapas distintas. Isso não transfere a conta, os logins ou a memória de Roger. [Instruções oficiais](https://help.openai.com/en/articles/11145903-connecting-github-to-chatgpt).

Se trabalhar no Codex, também pode clonar o repositório usando sua própria conta GitHub e abrir a pasta como projeto.

## 2. Receber autorização no RD

Solicitar ao administrador do Spazio acesso próprio ao RD Station **CRM** e ao **Marketing**, com a conta correta selecionada nos dois produtos. Gerar os próprios links de conexão no [Catálogo MCP RD Station](https://mcp.rdstationmentor.com/). Seguir [CONECTAR-RD.md](rd/CONECTAR-RD.md).

O link do repositório é compartilhável com pessoas autorizadas. Os links completos de conexão RD são credenciais pessoais e devem ficar nas configurações privadas do assistente.

## 3. Iniciar um chat com contexto

Selecionar GitHub e os dois conectores RD no novo chat. Usar [PROMPT-DE-RETOMADA.md](PROMPT-DE-RETOMADA.md). Pedir a leitura explícita dos arquivos principais; não supor que conectar o repositório carregou automaticamente todo o histórico.

Se a experiência do ChatGPT não oferecer criação de MCP, verificar plano, permissões e política do workspace com o administrador. A documentação consultada descreve o suporte completo a MCP personalizado para Business e Enterprise/Edu. O Codex com MCP HTTP configurado é uma rota alternativa. [Documentação do ChatGPT](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt).

## 4. Fazer a primeira conferência

Pedir somente consultas: listar funis, etapas do PRINCIPAL e campos do Marketing; comparar com os IDs de `rd/validacao-2026-11-23.json`. Nome de funil isoladamente não comprova que a conta é a correta: conferir também os IDs e o contexto do Spazio.

Depois, obter o mês atual com as definições de `rd/CRITERIOS-E-CONSULTAS.md`. Se faltarem páginas, UTMs ou autorização, registrar a limitação e preservar o último relatório.

## 5. Rever pendências antes de alterar a operação

Confirmar com o responsável atual as ofertas, turmas, verba e campanhas vigentes. O histórico inclui autorizações antigas e automações interrompidas; nenhuma delas é uma solicitação atual para reativar campanhas, disparar mensagens ou alterar o RD.
